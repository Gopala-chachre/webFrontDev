Class

class and id are the attributes of html elements. The class attribute is used to define a class for an element, which can be used to apply CSS styles or select elements using JavaScript. The id attribute is used to define a unique identifier for an element, which can also be used for styling and scripting purposes.

The main difference between class and id is that class can be used to define multiple elements with the same class name, while id should be unique for each element. In other words, you can have multiple elements with the same class name, but only one element with a specific id value.
& id's are often used for JS manipulation, while classes are often used for styling purposes. Additionally, class names can be reused across different elements, while id values should be unique within a page.

iFrame

An iframe is an HTML element that allows you to embed another HTML document within the current document. It creates a rectangular area on the page where the content of the embedded document is displayed. The embedded document can be from the same website or from a different website, and it can contain any type of content, including text, images, videos, and interactive elements.
